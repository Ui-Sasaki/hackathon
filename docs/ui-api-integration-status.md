# UI基準のフロントエンド・バックエンド接続状況

最終確認日: 2026-08-31

この文書は、API一覧ではなく、現在の `tetote/` に存在する画面と操作を基準に、バックエンドAPI、APIクライアント、画面接続の状況を整理したものである。

## 凡例

| 記号 | 意味 |
|---|---|
| ✅ | 実装・接続済み |
| 🟡 | 一部実装、または接続に制約あり |
| ❌ | 未実装、または操作不能 |
| 🧪 | モック、ローカルデータ、またはインメモリ実装 |
| ― | 画面内の入力・編集・遷移であり、API不要 |

## 現在の注意事項

- 応募画面はAPIへ接続されているが、依頼一覧が固定データかつ数値IDであるため、実際のAPI上の依頼IDと一致せず、応募に失敗する可能性が高い。
- マッチ、チャット、完了報告、評価、実績、本人確認、通報、ブロックはエンドポイント自体は存在する。チャットはMemory/Postgres Repository境界とフロントAPI接続があるが、Realtime購読は未実装である。
- `API不要` は、サーバーに保存・同期する必要がない一時的な入力、編集、画面遷移だけを指す。
- 文字サイズ、通知、位置情報などを複数端末で同期する場合は設定APIへの接続が必要である。
- 保存依頼や非表示依頼を再訪問後も維持する場合は、永続化用APIが必要である。
